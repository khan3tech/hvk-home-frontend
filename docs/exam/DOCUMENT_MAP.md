# Exam Documentation Map — Frontend

The exam UI is integrated into this repository. Use these files as the handoff and maintenance guide:

- `EXAM_FRONTEND_IMPLEMENTATION.md` — frontend-specific routes, screens, API usage, session handling, camera/fullscreen behavior, and local verification.
- `reference/` — complete documentation transferred from the standalone exam project so the full product context remains available without re-explaining requirements.

The frontend consumes the backend exam contract and owns the invitation flow, exam experience, camera permission gate, fullscreen/tab monitoring, autosave, manual submission confirmation, and user-facing error states. Existing repository documentation was preserved; transferred reference copies are kept in `reference/`.
